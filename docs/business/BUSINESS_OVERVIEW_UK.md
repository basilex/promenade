**Версія**: 0.1.0  
**Останнє оновлення**: 6 січня 2026  
**Статус**: Активна розробка (Фаза 2 - 50% завершено)

---

## Коротко про головне

**Promenade Platform** — це сучасна корпоративна система управління бізнесом, розроблена для оптимізації відносин з клієнтами, обробки замовлень, управління запасами та виставлення рахунків. Побудована на передових принципах архітектури програмного забезпечення, Promenade пропонує бізнесу масштабовану та надійну основу для управління ключовими операціями.

### Чим Promenade відрізняється від інших?

- **Модульна архітектура**: Додавайте лише ті функції, які потрібні саме вам
- **Подієва архітектура**: Оновлення в реальному часі та безшовна інтеграція між модулями
- **Корпоративна безпека**: Рольовий контроль доступу з JWT-автентифікацією
- **API-First підхід**: Повний REST API з інтерактивною документацією
- **Підтримка кількох БД**: Розгортайте на PostgreSQL, SQLite або MySQL
- **Готовність до продакшену**: 2200+ автоматизованих тестів гарантують надійність

## Бізнес-цінність

### Для малого бізнесу

- **Швидке налаштування**: Почніть роботу за 5 хвилин з SQLite (без потреби в інфраструктурі)
- **Економічність**: Open-source без ліцензійних платежів
- **Готовність до зростання**: Масштабуйтесь від соло-операцій до багатокористувацьких команд

### Для середніх компаній

- **Інтегровані операції**: Єдина платформа для CRM, замовлень, запасів та виставлення рахунків
- **Автоматизація процесів**: Зменшіть ручну роботу за допомогою автоматизованих робочих процесів
- **Аналітика в реальному часі**: Приймайте рішення на основі даних з вбудованою звітністю

### Для великих підприємств

- **Висока продуктивність**: Обробляйте 377,000+ подій на секунду
- **Розподілена архітектура**: Redis-based для розгортання на кількох інстансах
- **Безпека та відповідність**: RBAC, аудит-трейли, JWT-автентифікація
- **Розширюваність**: API-first дизайн для інтеграцій на замовлення

## Основні можливості

### 1. Управління взаємовідносинами з клієнтами (CRM)

**Статус**: ✅ Готово до продакшену

Керуйте повним життєвим циклом клієнта від першого контакту до лояльного покупця:

- **Управління клієнтами**
  - Відстеження життєвого циклу: Лід → Потенційний → Клієнт → Відтік
  - Сегментація клієнтів за рівнями (Безкоштовний, Базовий, Про, Корпоративний)
  - Гнучка система тегів для кастомної категоризації
  - Призначення менеджера продажів та відстеження джерел

- **Управління компаніями** (B2B)
  - Управління юридичними особами з податковими ID
  - Ієрархії материнська-дочірня компанії
  - Класифікація за галузями та відстеження кількості співробітників
  - Управління контактною та фінансовою інформацією

- **Воронка продажів**
  - Візуальний пайплайн з 5 етапами
  - Автоматичний розрахунок ймовірності на кожному етапі
  - Відстеження виграних/програних угод з причинами
  - Прогнозування доходів та аналітика

- **Відстеження взаємодій**
  - Записуйте всі точки контакту з клієнтом (дзвінки, емейли, зустрічі, нотатки)
  - Багатоучасницькі зустрічі з JSONB учасниками
  - Управління наступними діями та нагадування
  - Відстеження тривалості для контролю часу

- **Аналітика та звіти**
  - Дашборди огляду клієнтів
  - Статистика пайплайну продажів
  - Метрики продуктивності менеджерів
  - Аналіз часових рядів доходів
  - Інсайти конверсійної воронки

**Бізнес-вплив**:
- Зменшення відтоку клієнтів на 30% завдяки проактивному управлінню
- Підвищення продуктивності продажів на 40% завдяки автоматизованому відстеженню
- Покращення точності прогнозів на 25% завдяки аналітиці в реальному часі

### 2. Управління замовленнями

**Статус**: ✅ Готово до продакшену

Ефективна обробка замовлень від створення до виконання:

- **Обробка замовлень**
  - Автонумерація замовлень (формат ORD-YYYY-NNNNNN)
  - Підтримка кількох валют для міжнародних продажів
  - Управління позиціями з автоматичними підсумками
  - Машина станів: в обробці → підтверджено → обробляється → виконано

- **Життєвий цикл замовлення**
  - Правила валідації запобігають некоректним переходам станів
  - Кінцеві стани (виконано, скасовано) незмінні
  - Відстеження скасувань з причинами
  - Точки інтеграції для оплати та доставки (заплановано)

**Бізнес-вплив**:
- Обробка замовлень на 60% швидше завдяки автоматизації
- Зменшення помилок в замовленнях на 80% завдяки правилам валідації
- Покращення задоволеності клієнтів завдяки прозорому відстеженню

### 3. Управління складом та запасами

**Статус**: 🔄 В процесі (50% завершено)

Відстежуйте рівні запасів та руху товарів з точністю:

- **Управління запасами** ✅
  - Відстеження запасів в реальному часі (на складі, зарезервовано, доступно, зобов'язано)
  - Управління точкою перезамовлення (мін/макс пороги)
  - Розрахунок середньозваженої вартості
  - Сповіщення про низькі запаси (заплановано)

- **Відстеження руху товарів** ✅
  - Повний аудит-трейл для всіх змін запасів
  - 8 типів рухів: надходження, резервування, списання, коригування, переміщення, пошкодження, повернення
  - Зв'язування референсів з замовленнями та закупівлями
  - Відстеження локацій для переміщень
  - Історична аналітика (зведення за останні 30 днів)

- **Скоро з'являться** (Q1 2026)
  - Управління каталогом продуктів
  - Управління складськими локаціями
  - Інтеграція з обробкою замовлень (авто-резервування)
  - Сповіщення про низькі запаси та автоматичне перезамовлення

**Бізнес-вплив**:
- Зменшення дефіциту на складі на 50% завдяки проактивному управлінню перезамовленнями
- Покращення точності запасів до 99%+ завдяки аудит-трейлам
- Зниження витрат на утримання запасів на 20% завдяки оптимізованим рівням

### 4. Виставлення рахунків та платежі

**Статус**: ✅ Готово до продакшену

Оптимізуйте виставлення рахунків та збір платежів:

- **Управління рахунками**
  - Автоматичне генерування рахунків
  - Деталі позицій з розрахунками податків
  - Відстеження термінів оплати та прострочених рахунків
  - Генерування PDF (заплановано)

- **Обробка платежів**
  - Кілька методів оплати (картка, банківський переказ, готівка)
  - Відстеження статусу платежу (в обробці, завершено, не вдалося, повернуто)
  - Зв'язування рахунків та звірка
  - Інтеграція платіжних шлюзів (заплановано)

- **Управління підписками**
  - Автоматизація рекурентного виставлення рахунків
  - Управління тарифами (пробний, активний, скасований, закінчений)
  - Пільгові періоди та авто-продовження
  - Відстеження скасувань з причинами

**Бізнес-вплив**:
- Зменшення часу обробки рахунків на 70%
- Покращення грошового потоку завдяки автоматизованим нагадуванням
- Зменшення часу звірки платежів на 80%

### 5. Управління ідентифікацією та доступом

**Статус**: ✅ Готово до продакшену

Захистіть свою платформу корпоративною автентифікацією:

- **Управління користувачами**
  - Реєстрація та автентифікація користувачів
  - Політики паролів та управління
  - Відстеження статусу акаунта (активний, призупинений, заблокований)
  - Відстеження невдалих спроб входу та авто-блокування

- **Управління контактами**
  - Зберігання email, телефону та адреси з валідацією
  - Призначення основного контакту
  - Робочі процеси верифікації (email, телефон)
  - Контроль видимості публічний/приватний

- **Управління профілями**
  - Особиста інформація (ім'я, біо, аватар)
  - Локалізація (часовий пояс, мова, країна)
  - Соціальні посилання (LinkedIn, Twitter, GitHub)
  - Контроль приватності (публічний/приватний профіль)

- **Рольовий контроль доступу (RBAC)**
  - 5 системних ролей: суперадмін, адмін, менеджер, користувач, гість
  - 29+ деталізованих дозволів для всіх ресурсів
  - Гнучке призначення ролей
  - JWT токен-based автентифікація (15-хвилинний доступ, 7-денний refresh)

- **Функції безпеки**
  - Обмеження частоти запитів (вхід: 5/хв, реєстрація: 3/хв)
  - Відкликання токенів для виходу
  - CSRF захист
  - Аудит-трейли для чутливих операцій

**Бізнес-вплив**:
- Запобігання несанкціонованому доступу завдяки багаторівневій безпеці
- Зменшення навантаження на IT завдяки самообслуговуванню користувачів
- Забезпечення відповідності вимогам завдяки аудит-трейлам та контролю доступу

### 6. Управління довідковими даними

### Ключові архітектурні переваги

1. **Незалежні модулі**: Кожна бізнес-область може розвиватися незалежно
2. **Подієва архітектура**: Модулі спілкуються через події (оновлення в реальному часі)
3. **Масштабованість**: Додавайте більше серверів зі зростанням бізнесу
4. **Надійність**: 2200+ автоматизованих тестів забезпечують якість
5. **Гнучкість**: Виберіть PostgreSQL (продакшен) або SQLite (розробка)

### Технічні вимоги

**Всі додатки**:

1. **Інтеграція API**
   - Повинен використовувати Promenade REST API (146+ ендпоінтів доступно)
   - Документація API: Swagger UI + Postman колекція надаються
   - Автентифікація: JWT токени (access + refresh)
   - Дотримання обмежень rate limiting
   - Обробка помилок для всіх відповідей API

2. **Продуктивність**
   - Час початкового завантаження: <3 секунд
   - Плавні анімації та переходи 60fps
   - Ефективні патерни викликів API (кешування, пакетування)
   - Ледаче завантаження для великих списків

3. **Безпека**
   - Безпечне зберігання токенів (Web: httpOnly cookies; Mobile: Keychain/Keystore)
   - Валідація та санітизація вводу
   - Захист XSS та CSRF (веб)
   - Certificate pinning (мобільні, рекомендовано)

4. **Тестування**
   - Unit тести: 80%+ покриття коду
   - Інтеграційні тести для критичних потоків
   - E2E тести для ключових користувацьких подорожей
   - Тестування продуктивності та оптимізація

5. **Документація**
   - Гід інтеграції API
   - Бібліотека компонентів (веб)
   - Патерни управління станом
