## Como Contribuir / How to Contribute

Se você deseja ajudar com a tradução:

1. Escolha um documento da pasta `docs/` que ainda não foi traduzido
2. Crie uma tradução em `docs/pt/` com o sufixo `.pt.md`
3. Adicione um link no documento em inglês: `🇬🇧 English | 🇵🇹 Português | ...`
4. Atualize a lista acima
5. Crie um Pull Request

**Obrigado por ajudar a criar documentação em português!** 🇵🇹 🇧🇷
