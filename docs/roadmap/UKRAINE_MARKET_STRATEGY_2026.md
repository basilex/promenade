## Executive Summary

**Problem**: The ban on Russian software (1C, Bitrix24, AmoCRM) created a large vacancy in the Ukrainian CRM/ERP market for 150K+ SMBs.

**Solution**: Promenade provides a modern, cloud-ready platform with Ukrainian localization and compliance.

**Competitive Advantages**:
- Enterprise-grade architecture (DDD + Event-Driven)
- Go performance vs legacy 1C
- Full Ukrainian localization and compliance
- Modern security (JWT + RBAC)
- Low-code customization via LUA

**Target**: Capture 5-10% of the SMB market (7,500-15,000 companies) within 18 months.

**Projected Revenue** (7,500 clients):

**Наше рішення**: Promenade - сучасна, хмарно-орієнтована платформа з українською локалізацією та комплаєнсом.

**Конкурентна перевага**:
-  Архітектура Enterprise-рівня (DDD + Event-Driven)
-  Швидкість Go vs застарілі технології 1С

-  No-code кастомізація через LUA

#### 1.2. Українська Бухгалтерія (Базова) 
**Статус**: Відсутній (0%)  
**Criticality**:  БЛОКЕР для бухгалтерських фірм  
**Impact**: 50% target market  
**Timeline**: 4-5 тижнів

**Мінімальний Функціонал**:
1. **Податкові Накладні (ПН)**
   - Генерація ПН у форматі XML
   - Валідація згідно з вимогами ДПС
   - Реєстрація в ЄРПН (через M.E.Doc або Cabinet API)
   - Статуси: Draft → Registered → Cancelled

2. **ПДВ Облік**
   - Ставки: 20%, 7%, 0% (експорт)
   - Податковий кредит
   - Податкові зобов'язання
   - Декларація ПДВ (авто-розрахунок)

3. **Звітність ДПС**
   - Експорт у форматі XML (J12, J13, F01)
   - Інтеграція з M.E.Doc API
   - Інтеграція з Cabinet (Електронний Кабінет ДПС)

**Технічна Реалізація**:
```
Новий Context: internal/contexts/accounting/

Aggregates:
- TaxInvoice (Податкова Накладна)
- TaxDeclaration (Декларація)
- AccountingEntry (Проводка)

Value Objects:
- TaxRate (20%, 7%, 0%)
- EDRPOU (код ЄДРПОУ)
- TaxNumber (ІПН)

Integrations:
- pkg/accounting/medoc/ (M.E.Doc API)
- pkg/accounting/cabinet/ (Cabinet API)
```

**Database Schema**:
```sql
CREATE TABLE accounting_tax_invoices (
   id TEXT PRIMARY KEY,
   invoice_id TEXT REFERENCES billing_invoices(id),
    
    -- Податкова інформація
    tax_invoice_number VARCHAR(50) UNIQUE,
    tax_invoice_date DATE NOT NULL,
    tax_invoice_type VARCHAR(20), -- 'standard', 'correction', 'consolidated'
    
    -- Контрагент
    supplier_edrpou VARCHAR(10),
    supplier_ipn VARCHAR(12),
    supplier_name VARCHAR(255),
    customer_edrpou VARCHAR(10),
    customer_ipn VARCHAR(12),
    customer_name VARCHAR(255),
    
    -- Суми
    amount_without_vat INTEGER, -- в копійках
    vat_amount INTEGER,
    total_amount INTEGER,
    vat_rate INTEGER, -- 20, 7, 0
    
    -- Статуси
    status VARCHAR(20), -- 'draft', 'registered', 'cancelled'
    registration_number VARCHAR(50), -- номер реєстрації в ЄРПН
    registered_at TIMESTAMP,
    
    -- XML
    xml_content TEXT,
    
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**Example Usage**:
```go
// Create Tax Invoice from regular Invoice
taxInvoice := accounting.NewTaxInvoice(invoice)
taxInvoice.SetSupplier(company.EDRPOU, company.TaxNumber, company.Name)
taxInvoice.SetCustomer(customer.EDRPOU, customer.TaxNumber, customer.Name)
taxInvoice.CalculateVAT(20) // ПДВ 20%

// Generate XML
xml := taxInvoice.GenerateXML()

// Register in ЄРПН
registrationNumber, err := medocClient.RegisterTaxInvoice(xml)
```

**Технічна Реалізація**:
```
Новий Context: internal/contexts/banking/

Aggregates:
- BankAccount (Рахунок)
- BankStatement (Виписка)

- pkg/banking/monobank/
```

**API Example**:
```go
// Configure bank integration
bankAccount := banking.NewBankAccount(
    "UA123456789012345678901234",  // IBAN
    "monobank",                     // Provider
    "bank_token_here",              // API token
)

// Sync transactions
transactions, err := bankAccount.SyncTransactions(
    time.Now().AddDate(0, 0, -7), // Last 7 days
    time.Now(),
)

// Auto-match with invoices
for _, tx := range transactions {
    if invoice := findInvoiceByAmount(tx.Amount); invoice != nil {
        invoice.MarkAsPaid(tx.ID, tx.PaidAt)
        // Event: invoice.paid
    }
}
```

##  Risks & Mitigation

### Risk 1: Конкуренти швидше додадуть український комплаєнс
**Probability**: MEDIUM  
**Impact**: HIGH  
**Mitigation**:
- Швидкий розвиток (2-3 місяці до MVP)
- Фокус на технічній перевазі (архітектура)
- Краща ціна

### Risk 2: Зміни законодавства (ДПС, ПРРО)
**Probability**: MEDIUM  
**Impact**: MEDIUM  
**Mitigation**:
- Модульна архітектура (легко змінити)
- Моніторинг змін законодавства
- Швидкі hotfixes (1-2 дні)

### Risk 3: Повільне прийняття ринком
**Probability**: LOW-MEDIUM  
**Impact**: HIGH  
**Mitigation**:
- Агресивний маркетинг
- Безкоштовний beta період
- Case studies і соц. докази

### Risk 4: Брак коштів на розробку
**Probability**: LOW  
**Impact**: HIGH  
**Mitigation**:
- Bootstrap (власні кошти)
- Pre-sales (продажі ще до повного релізу)
- Грант від українських фондів (USAID, EU4Business)
