# Documentación en Español / Spanish Documentation 🇪🇸

Esta carpeta contiene traducciones al español de la documentación de Promenade.

This folder contains Spanish translations of Promenade documentation.

---

## Estructura / Structure

```
docs/es/
├── INDEX.es.md                          # Índice de documentación en español
├── ARCHITECTURE_QUICKREF.es.md          # Referencia rápida de arquitectura
├── MODULE_DEVELOPMENT.es.md             # Desarrollo de módulos
└── ... (se añadirán más traducciones)
```

## Cómo Contribuir / How to Contribute

Si deseas ayudar con la traducción:

1. Elige un documento de la carpeta `docs/` que aún no esté traducido
2. Crea una traducción en `docs/es/` con el sufijo `.es.md`
3. Añade un enlace en el documento en inglés: `🇬🇧 English | 🇪🇸 Español | ...`
4. Actualiza la lista anterior
5. Crea un Pull Request

**¡Gracias por ayudar a crear documentación en español!** 🇪🇸
