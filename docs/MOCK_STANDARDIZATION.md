## Mock File Structure (Standard)

All mocks now follow this pattern:

```go
// Code generated by mockery v2.53.5. DO NOT EDIT.

package mocks

import (
    // imports...
)

// Mock{InterfaceName} is an autogenerated mock type
type Mock{InterfaceName} struct {
    mock.Mock
}

// Method implementations with proper type safety...
```

## Workflow (Standard)

### For Developers

1. **Change an interface** (add/modify method)
2. **Regenerate mocks**: `make mocks` or `make mocks-{module}`
3. **Update tests** to use new mock signatures
4. **Commit both** interface and mock changes

### For CI/CD

Add to pipeline:

```yaml
- name: Install mockery
  run: make install

- name: Verify mocks are up-to-date
  run: make mocks-verify
```
