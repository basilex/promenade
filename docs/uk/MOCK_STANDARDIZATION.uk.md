## Структура файлу Mock-об'єкта (стандарт)

Усі mock-об'єкти тепер дотримуються цього патерну:

```go
// Code generated by mockery v2.53.5. DO NOT EDIT.

package mocks

import (
    // imports...
)

// Mock{InterfaceName} is an autogenerated mock type
type Mock{InterfaceName} struct {
    mock.Mock
}

// Method implementations with proper type safety...
```

## Робочий процес (стандарт)

### Для розробників

1. **Змініть interface** (додайте/змініть метод)
2. **Регенеруйте mock-об'єкти**: `make mocks` або `make mocks-{module}`
3. **Оновіть тести** для використання нових сигнатур mock
4. **Закомітьте обидва** зміни в interface та mock

### Для CI/CD

Додайте до pipeline:

```yaml
- name: Install mockery
  run: make install

- name: Verify mocks are up-to-date
  run: make mocks-verify
```
