## Модульна Плагін Система

**Модульна система** Promenade дозволяє будувати додатки як колекції незалежних, багаторазових модулів.

### Що таке Модуль?

Кожен модуль - це **повний вертикальний зріз**:

- Власні доменні сутності
- Власні репозиторії
- Власні use cases
- Власні HTTP обробники
- Власні міграції бази даних
- Власна конфігурація

### Доступні Модулі

**Безкоштовні Модулі:**

- **Posts** - Користувацький контент (пости, коментарі, лайки)
- **Profiles** - Профілі користувачів та контакти
- **Analytics** - Метрики, звіти, дашборди

**Комерційні Модулі:**

- **Billing** - Управління підписками, інвойсинг, платежі
- **Audit** - Незмінні аудит-логи з криптографічними підписами
- **Warehouse** - Управління складом (скоро)

### Незалежність Модулів

```go
// Кожен модуль реалізує цей інтерфейс
type IModule interface {
    Initialize(ctx, core) error
    RegisterRoutes(router)
    RegisterMigrations() []Migration
    RegisterPermissions() []Permission
    Start(ctx) error
    Stop(ctx) error
}
```

### Увімкнення/Вимкнення Модулів

```yaml
# config/modules.yaml
modules:
  enabled:
    - posts
    - profiles
    - analytics
    # - warehouse  # Вимкнути закоментувавши
```

### Переваги

✅ **Справжня незалежність** - Модулі не імпортують один одного  
✅ **Динамічне завантаження** - Увімкнення/вимкнення без змін коду  
✅ **Власні міграції** - Кожен модуль має незалежну історію схеми  
✅ **Ліцензування** - Продавайте комерційні модулі окремо
